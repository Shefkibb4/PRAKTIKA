# PRAKTIKA
Praktika në GitHub

Ky repository është krijuar për të dokumentuar dhe organizuar punën time gjatë praktikës profesionale, duke përdorur GitHub si platformë për ruajtjen, menaxhimin dhe versionimin e projekteve.

📌 Rreth repository-t

Në këtë repository do të publikohen detyrat, ushtrimet dhe projektet që realizohen gjatë praktikës. GitHub përdoret për të ruajtur kodin në mënyrë të organizuar dhe për të ndjekur ndryshimet dhe progresin e projekteve.

🔗 Përdorimi i GitHub

Gjatë praktikës, GitHub përdoret për:

Ruajtjen e projekteve dhe kodit.
Organizimin e skedarëve dhe repository-ve.
Menaxhimin e versioneve të projektit.
Publikimin e ndryshimeve përmes commit-eve.
Krijimin dhe menaxhimin e branch-eve.
Bashkëpunimin dhe ndarjen e projekteve.
Dokumentimin e punës përmes README-ve.
📂 Organizimi

Çdo projekt ose detyrë mund të organizohet në repository-n përkatës, në mënyrë që puna të jetë e lehtë për t'u gjetur, mirëmbajtur dhe zhvilluar më tej.

🎯 Qëllimi

Qëllimi i këtij repository është të krijojë një histori të organizuar të punës gjatë praktikës dhe të tregojë progresin në përdorimin e Git dhe GitHub, si dhe në zhvillimin e projekteve softuerike.

🚀 Progresi

Repository do të përditësohet vazhdimisht me punë të reja, përmirësime dhe projekte të realizuara gjatë praktikës.

Çdo commit dhe ndryshim i publikuar në GitHub përfaqëson një pjesë të progresit dhe eksperiencës së fituar gjatë kësaj periudhe.
